Il tecnico Monday ha fornito linee guida su come gestire le email columns:

✓ Input Field Method: Usare l'etichetta della colonna o il valore email
✓ GraphQL Query Method: Accedere ai campi email + label della colonna
✓ Supporto per etichette configurate in Monday (display text vs actual email)

follow-up o stai analizzando i dati in modo diverso?"

│                                                                       │

│  Location: controllers/emailController.js (linee 50-95, 206-209)    │

│  • Se Input Field non disponibile, accetta itemId + columnId       │

│                                                                       │
│  Query GraphQL:                                                     │
│  {                                                                  │
│    items(ids: [itemId]) {                                          │
│      column_values(ids: "columnId") {                              │
│        text   ← etichetta/label                                    │
│        value  ← JSON raw della colonna                             │
│      }                                                              │
│    }                                                                │
│  }                                                                  │
│                                                                       │
│  Vantaggi:                                                          │
│  ✓ Accesso completo a label + email                                │
│  ✓ Supporta etichette Monday                                       │
│  ✓ Flessibile per casi avanzati                                    │
│                                                                       │
│  Limitazioni:                                                       │
│  ✗ 2 richieste HTTP (più lentezza)                                 │
│  ✗ Richiede token Monday API                                       │

Per validare correttamente la nostra implementazione e assicurarci di
supportare al 100% le email columns con etichette, abbiamo UNA domanda:

┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Quando una EMAIL COLUMN viene collegata come INPUT FIELD in una  │
│  Monday automation recipe, QUALE VALORE riceve il nostro endpoint  │
│  nel campo inboundFieldValues.recipientEmail?                      │
│                                                                     │
│  Scenario: Colonna email in Monday con:                            │
│  ├─ Etichetta: "Work email"                                       │
│  └─ Email: "alice@company.com"                                    │
│                                                                     │
│  Opzioni:                                                           │
│                                                                     │
│  A) SOLO L'EMAIL                                                   │
│     { "recipientEmail": "alice@company.com" }                      │
│     → Cosa noi riceviamo: "alice@company.com"                      │
│                                                                     │
│  B) SOLO L'ETICHETTA                                               │
│     { "recipientEmail": "Work email" }                             │
│     → Cosa noi riceviamo: "Work email" (NON è un'email valida!)    │
│                                                                     │
│  C) OGGETTO CON ENTRAMBI                                           │
│     { "recipientEmail": {                                          │
│         "label": "Work email",                                    │
│         "email": "alice@company.com"                              │
│       }                                                             │
│     }                                                              │
│     → Cosa noi riceviamo: oggetto con label + email                │
│                                                                     │
│  D) ALTRO FORMATO (quale?)                                         │
│                                                                     │
│  ⚠️  QUESTO è CRITICO perché:                                     │
│      • Scenario A: ✓ Funziona perfettamente                       │
│      • Scenario B: ✗ Fallisce (no "@") → necessario GraphQL       │
│      • Scenario C: ✓ Funziona (già supportato)                    │
│      • Scenario D: Dipende dal formato specifico                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
