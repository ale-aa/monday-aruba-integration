✅ METODO 1: INPUT FIELD (Primario - Consigliato)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

La nostra Monday recipe trasmette il valore della email column direttamente come Input Field nel payload.

Vantaggi:
• 1 sola richiesta HTTP
• No query GraphQL aggiuntive
• Supporta nativamente etichette di colonna
• Migliore performance

Codice di estrazione: controllers/emailController.js (linee 164-201)
- Gestisce formato stringa diretta
- Gestisce formato oggetto con fallback (email → text → value)
- Valida il risultato finale


✅ METODO 2: COLUMN ID + GraphQL (Fallback)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Se l'Input Field non è disponibile, usiamo itemId + columnId per queryare via GraphQL e accedere ai campi raw della colonna.

Query:
{
  items(ids: [itemId]) {
    column_values(ids: "columnId") {
      ... on EmailValue {
        email
        label
      }
    }
  }
}

Codice di estrazione: controllers/emailController.js (linee 50-95)
- Accesso a email e label separatamente
- Estrae il valore effettivo per l'invio
